Install Synapse

Download the Windows x64 installer from the official GitHub release. Choose the file ending in _x64-setup.exe, run it, and follow the setup steps.

Download for Windows

Windows x64. The download opens the official release page.

First-run setup explains microphone access and optional speech downloads. You can skip them and return to Settings → Voice later. Synapse lives in the system tray while you work.

Set up local speech

For dictation, download the optional speech model in Settings → Voice. It’s about 630 MB. Once downloaded, transcription runs on your computer without an AI API key.

Select your microphone, focus a text field in another app, and start dictating. Press Enter or click the listening circle when you’re finished. Dictation doesn’t stop automatically on silence by default.

For local spoken replies, the optional voice engine downloads a runtime and model files using roughly 1-2 GB. Speak Selected Text can also use the operating system’s voice fallback.

Your AI provider, connected.

  1. Get an API key from your chosen provider: Anthropic, OpenAI or OpenRouter.
  2. Open Settings → AI and add the key for that provider.
  3. Choose a model, then open AI from the wheel to start a conversation.

Provider requests require internet access and may incur usage charges. Those charges are separate from any future Synapse purchase. Keys are stored in your OS credential store.

A little help, if you need it.

The shortcut doesn’t open the wheel.

Check that Synapse is running in the system tray. Another app may use the same shortcut; change it in Settings → Controls and try again.

Dictation isn’t picking up my voice.

Check Windows microphone permissions and your selected input device. Confirm that the speech model download is complete in Settings → Voice, and test in a normal text field.

AI replies aren’t working.

Check your internet connection, chosen provider, API key and provider billing. An ordinary chat subscription may not include API usage. Read the error shown in Synapse before trying again.

How do I update the app?

Open Settings → Updates to check for a release and choose when to install. The updater verifies the installer signature. Installing an update restarts Synapse.

Still stuck? Check or report an issue on GitHub. Don’t include API keys, private notes or clipboard contents in a public report.
