Website privacy.

A static website. No signup, account, or analytics added by Synapse.

Hosting

This website is published with GitHub Pages. GitHub processes connection information to serve the site. See GitHub’s privacy statement for its handling of that information.

What this page does

The wheel preview explains Synapse’s features. It does not access your microphone, clipboard, notes, AI keys, or desktop. The site does not collect email addresses, create accounts, set application cookies, or add analytics. Fonts and product images are served with the website. Your light or dark theme preference is saved in this browser’s local storage.

Downloads and external links

Download links open Synapse’s official GitHub release page. GitHub handles those requests under its own policies. The website does not process payments.

The desktop app

Synapse’s desktop features are separate from this website. Notes and clipboard history are stored on your computer. Dictation runs locally after the optional model download. AI requests go to the provider you configure, using your own API key.

Read the setup guide for local and online features. For website questions, contact the maintainer through the Synapse repository. Do not post private information in public issues.
